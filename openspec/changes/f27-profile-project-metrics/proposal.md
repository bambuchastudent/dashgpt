# Feature 27 — Profile project metrics

## Why

Add a compact, portable project metrics view to the user profile.

## What Changes

- Add a collapsible profile metrics header.
- Show estimated token usage plus explicit spent and donated totals.
- Store money totals in existing profile revisions.
- Keep token estimates visibly approximate.

## Impact

Touches profile UI, ChatGPT import metadata, Vault profile revisions, and regression coverage. Card and Dash semantics remain unchanged.
