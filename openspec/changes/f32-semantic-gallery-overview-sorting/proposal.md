## Why

The gallery needs a newest-first default and a true whole-board overview for large card collections.

## What Changes

- Time is the default order.
- Color and Tag are alternative presentation orders.
- Minimum zoom uses viewport-aware overview fitting while retaining every selected card.
- The same behavior applies to My Dash, filtered/search selections, and Semantic Dash members.

## Scope

This change affects gallery presentation only. It does not generate tags, change semantic colors, change search membership, change Dash membership, or change card storage identity.
