MVP POLICY

Privacy

DashGPT is designed to keep useful AI outcomes under the control of the person using the Vault.

Local Vault
Locally created/imported Results are stored in a portable DashGPT Vault in your browser. Clearing browser data can remove that local copy, so export or remote synchronization is recommended when the data matters.
GitHub Vault sync
If you explicitly connect a GitHub repository or folder, DashGPT uses a GitHub App installation to synchronize Vault objects. During GitHub installation you choose which repositories the app may access. DashGPT requests repository Contents read/write access because it needs to read and commit Vault files. The short-lived GitHub installation token is created and used server-side; it is not placed in the browser Vault, URL, Context Pack, or chat.
GitHub connection state
The browser receives only a signed HttpOnly session cookie identifying the selected repository/path and GitHub App installation. Disconnecting GitHub clears that DashGPT session and does not delete your local Vault or automatically delete the remote Vault files.
Published Results
An instance operator may publish Results with the site. Published Results and the public DashGPT instance protocol are delivered by that operator's hosting environment and may be visible to anyone who can access that site.
Remote DashGPT instances
When you give the DashGPT plugin another HTTPS DashGPT site URL, the plugin gateway may contact that site to verify that it is a compatible DashGPT instance and read the published Results or Context Packs you requested. The site operator controls that instance and its logs.
ChatGPT shared links
If you provide a public ChatGPT share URL for ingestion, the DashGPT server may fetch that public conversation in order to create a Result. Do not use public share links for material you do not intend to expose through that link.
Plugin imports
The DashGPT MCP tool prepares a Result and an explicit import link. The import happens when you open that link. The MVP does not silently write a prepared Result into your browser or another person's DashGPT instance.
Data minimization
Raw chat transcripts are not part of normal Vault synchronization. DashGPT stores distilled Results and explicitly selected provenance. Passwords, API keys, provider tokens, payment data and private document identifiers should not be put into a Result or portable Vault.
Self-hosting
When DashGPT is self-hosted, the person or organization operating that instance controls its hosting, logs, access policy, backups, secrets, and published content.
