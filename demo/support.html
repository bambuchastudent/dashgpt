DashGPT support

DashGPT is an early public MVP for keeping useful AI outcomes as durable Results, reopening living topic Dashes, and moving context between chats and agents.

Before reporting a problem
Include what you were trying to do, the DashGPT site URL you used, whether the issue happened in the dashboard or ChatGPT plugin, and the exact visible error. Never send passwords, API keys, access tokens, payment details, or private identity-document numbers.
Known MVP boundary
The public plugin can read Results and Dashes intentionally exposed by a compatible HTTPS DashGPT instance and prepare an explicit browser import link. It cannot inspect an unexposed browser/private-provider Vault and does not silently write Results or Dashes into another person's storage.
Self-hosted instances
The operator of a self-hosted DashGPT instance is responsible for its hosting, access controls, logs, backups, availability, and published content.
Contact
For the current MVP, open an issue in the DashGPT GitHub repository and provide only the minimum information needed to reproduce the problem.
